# nekoplayer

nekoplayer is an Android app for watching anime with subtitles and turning new Japanese vocabulary into AnkiDroid cards.

Watch videos from your device, load subtitles and tap Japanese words to look them up in your dictionaries. When you find something worth learning, mine it to AnkiDroid with the subtitle, audio and screenshot.

You can import Yomitan dictionaries and search Jimaku for subtitles. Jimaku search requires an API key; AnkiDroid must be installed to create cards.

## Requirements

- Android 6.0 or later
- AnkiDroid to mine cards
- A Jimaku API key to search Jimaku
